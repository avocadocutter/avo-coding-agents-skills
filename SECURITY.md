# Security Policy

## Reporting a Vulnerability

If you find a security issue in this project, please **do not open a public GitHub issue**.

Report it privately by emailing: me@lopezserg.io

Include:
- A description of the issue and its potential impact
- Steps to reproduce or a proof of concept
- Any relevant file paths or commit references

You can expect a response within 7 days. If the issue is confirmed, a fix will be prioritized and you'll be credited in the release notes unless you prefer otherwise.

## Out of Scope

- Issues in dependencies (report those upstream)
- Theoretical vulnerabilities without a realistic attack scenario
